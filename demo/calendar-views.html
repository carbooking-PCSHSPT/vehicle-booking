เน้นดูง่าย เห็นภาพรวม ไม่รก · ทุกแบบสลับ "เดือน / สัปดาห์" ได้ และกดเลือกวันเพื่อดูรายละเอียด · ข้อมูลตัวอย่าง

แบบ A · จุดสี + แผงรายละเอียดแบบ B · แผนที่ความหนาแน่น + ตารางรถแบบ C · ปฏิทินเล็ก + รายการตามวัน
แบบ A

จุดสีบอกจำนวนงาน + แผงรายละเอียดด้านข้าง

เดือน: แต่ละวันมีแค่ตัวเลขกับจุดสีตามสถานะ กดวันแล้วรายละเอียดขึ้นด้านขวา · สัปดาห์: ตารางเวลาแบบ Google Calendar เห็นช่วงเวลาชัด

แบบ B

แผนที่ความหนาแน่น (จำนวนรถที่ใช้) + ตารางรถรายสัปดาห์

เดือน: สียิ่งเข้ม = วันนั้นใช้รถมาก เห็นทันทีว่าวันไหนรถเหลือน้อย · สัปดาห์: แถว = รถแต่ละคัน รู้เลยว่าคันไหนว่างวันไหน

แบบ C

ปฏิทินเล็ก + รายการเรียงตามวัน

เดือน: ปฏิทินเล็กบอกจำนวนงาน ด้านขวาเป็นรายการเรียงวัน อ่านง่ายเหมือนสมุดนัด · สัปดาห์: แถว = วัน แกนนอน = เวลา
